## Visual rules

- Cell size: 32x32 px (all animations of a character use the same cell)
- Pixels Per Unit: 32
- Outline: selective
- Light direction: top-left
- Shading layers: 2
- Dithering: none
- Max colours per sprite: 16
- Proportions: chibi

## Do

- Draw every sprite on the 32x32 cell; import with PPU 32, Filter Point, Compression None.
- Use only the 16 colours of palette.hex, at most 16 per sprite.
- Selective outline: outline each area with a darker shade of its own ramp; use the outline colour #000000 only where the silhouette meets the background.
- Light comes from the top-left: lit pixels on the top-left side, shadows toward the bottom-right.
- Use 2 shade step(s) per material, taken from the ramps in game-style.json.
- Chibi proportions: big head (about 1/2 of the body height) - see `blueprint --style chibi`.
- Keep the mood cozy, retro: warm colours, medium saturation, high contrast.

## Don't

- Don't add colours outside palette.hex - ask first; after approval use game-palette-add.
- Don't use anti-aliasing or semi-transparent pixels (alpha only 0 or 255).
- Don't dither.
- Don't use pillow shading (light from every side) or light from the bottom-right.
- Don't mix pixel sizes: no scaled, rotated or sub-pixel-moved sprites; 1 sprite pixel = 1 texel.
- Don't change the cell size between animations of one character.
- Don't use a pure dark outline all around every shape.
